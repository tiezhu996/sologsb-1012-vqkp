# SignCourse Studio · 手语课程编排工具

SignCourse Studio 是面向手语教师的课程设计工作台。教师可以把示范片段、手形说明、字幕、镜头角度、常见错误和练习任务组合为学习步骤，并在手机和平板预览中检查字幕安全区、步骤依赖和替代文本。

## 功能

- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，并运行带检查点的动作时间线。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、练习反馈不完整和常见错误缺失。
- 状态流转：支持草稿、提交复核、退回修改、冻结版本和基于冻结版本创建修订版。
- 离线编辑：所有修改保存在 `localStorage`；浏览器离线或刷新后可继续编辑。
- 离线课程包合并：电脑端可导出课程到平板，平板离线修改字幕、步骤与前置条件后导出离线包，回到电脑端三向合并。
  - 按模块和步骤编号（稳定 ID）识别两边改动：不同位置的改动直接合并；同一位置两边都改过且内容不同时先保留两份、逐字段标出差异，教师逐处选择后才生效。
  - 步骤顺序只有一边调整时直接采用新顺序，两边调整结果不同时保留两套顺序供选择；前置条件按步骤 ID 随对应步骤迁移，前置步骤被删除时清空悬空引用并提醒。
  - 一边删除、另一边修改时要求在「保留修改 / 执行删除」间选择；已冻结版本始终保持原样，合并只写入工作稿并回到草稿状态。
  - 导入逐模块处理并在每个检查点持久化；中断后（含刷新、关闭页面）可从中断处恢复，已处理模块与待选冲突继续保留。
  - 仍有待选择冲突时不能应用合并，也不能提交复核或冻结。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + S` 保存草稿、`Alt + ↑/↓` 调整步骤顺序。

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 离线课程包合并流程

界面右上角的「电脑 / 平板」切换用于模拟教研室电脑与教师平板两台设备：

1. **电脑端**：打开课程工作稿，点「导出课程到平板」，下载 `.signcourse` 风格的 JSON 离线包（导出时的共同快照会随包携带）。
2. **平板端**：切到「平板」进入离线工作台（数据独立保存在 `localStorage`），离线修改字幕、步骤顺序、前置条件等，完成后点「导出离线包带回」。
3. **电脑端**：点「导入合并」，可直接选择离线包文件，或选择「导入本机最近导出的离线包」（同一浏览器演示用）。
4. 合并弹层逐模块显示处理进度：自动合并的改动列出来源；同位置两边都改的字段展示「共同原稿 / 电脑工作稿 / 平板离线稿」三份内容，逐处选择；删除-修改冲突、顺序冲突同样需要选择。全部选完后「应用合并到工作稿」才会真正写入。
5. 弹层中的「模拟导入中断」可设置处理完前 N 个模块后中断，用于验证断点恢复：中断现场写入 `localStorage`，刷新后顶部出现恢复横幅，「从中断处继续」不会重复处理已完成模块。

合并的核心算法（字段级与有序列表三向合并、冲突识别、前置条件迁移、断点续跑）位于 `src/merge.ts`，单元测试见 `src/components/app-root/merge.spec.ts`：

```bash
npm test            # 纯逻辑单元测试（jest spec）
npm run test:e2e    # 单元测试 + 浏览器 e2e（需 puppeteer）
```

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
